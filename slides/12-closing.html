A Demonstration · A Charter

A demonstration, not a destination.

It is a demonstration of an architecture, not a finished platform — and the road from here is concrete.

Honest Limitations

What this project is not.

I.
Sepolia testnet only.

No mainnet contract. No L2 deploy. No audit against mainnet gas-cost expectations — explicitly out of scope for the three-day demonstration build.

II.
Single-EOA institution model.

Each institution is one externally-owned account. No on-chain multisig (Safe) for issuance authority; no rotation of a compromised wallet without owner intervention.

III.
No subgraph indexer.

Listing operations enumerate every token via eth_call — O(n) and slow at scale. A Graph subgraph that indexes the five contract events would close this gap.

IV.
Front-end exercised manually.

No Playwright or Cypress regression suite. The fifteen-step manual demonstration in Chapter 4 is the closest the project comes to integrated UI tests.

Future Scope · A Short Charter

The road ahead.

I.
Mainnet & L2 deploy — gas-optimised.

Hash the strings off-chain rather than SSTOREing them; reconstruct from IPFS at read time. Approximately 70 % per-issuance gas reduction, with L2 cutting another order of magnitude. §5.4.1

II.
Multi-signature institutions via Safe.

Replace onlyApprovedInstitution with a check against IERC1271.isValidSignature — M-of-N co-signers, no single registrar holding unilateral issuance authority. §5.4.2

III.
Zero-knowledge revocation proofs.

Batch revocations into a Merkle tree; publish only the root. A verifier checks a certificate's status without learning the status of any other. §5.4.7

IV.
CI/CD & Playwright smoke tests.

The lowest-cost-highest-value engineering item: GitHub Actions running npm test on every PR plus a full headless UI flow against Hardhat-localhost. Catches ~90 % of regressions before Sepolia. §5.4.10
